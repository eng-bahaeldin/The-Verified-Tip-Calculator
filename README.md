# The Verified Tip Calculator

A simple tip calculator web app that lets a user enter a bill amount and tip percentage, then calculates the tip and total bill amount.

## Features
- Enter a bill amount
- Enter a tip percentage
- Click the calculate button
- View the tip amount and total bill

## How to Run
1. Open the project folder in your browser.
2. Launch `index.html` directly in a browser, or use a local development server if you prefer.
3. Enter a bill amount and tip percentage.
4. Click the Calculate Total button to see the results.

## AI Tool / Prompt Usage
This project was assisted with GitHub Copilot and AI-generated JavaScript logic for the bill calculation.

Example prompt used:
> "Act as a JavaScript developer. Write a function called calculateBillTotals that accepts bill and tipPercentage and returns the tip amount and grand total rounded to two decimal places."

The AI-generated function was then connected to the HTML form so the inputs are parsed as numbers and the output is displayed in the page.
